# Troubleshooting

Each guide is a set of steps an AI agent (or you) can run in order: **symptoms → checks → fixes → verify.** You can also paste any guide into an AI chat and say "help me work through this."

**Start here:** Start menu → **TurtleMaxxxing** → **Check my TurtleMaxxxing install** (or run `scripts\check-install.ps1`). It reports the version, whether the app answers, port problems and folder warnings, without any of your data. Its report tells you, or whoever's helping, which guide below fits. No Claude Code? Paste the report and the [free help prompt](../HELP_PROMPT.md) into any Claude chat.

| Symptom | Guide |
|---|---|
| The app won't start, or closes right away | [app-wont-start.md](app-wont-start.md) |
| The browser shows a blank page, an old version, or "Not Found" | [blank-or-old-page.md](blank-or-old-page.md) |
| A balance or the cash flow looks wrong | [numbers-look-wrong.md](numbers-look-wrong.md) |
| Something broke after an update or change, and I want it back | [restore-and-undo.md](restore-and-undo.md) |

**Before you start:** these guides never need your passwords, and never need anyone to read or share your budget data. If an AI asks to open your data folder, it should say exactly why and ask first.
